# 用户手动修改优先保留规则 (User Manual Edits Preservation)

## 核心指令 (Critical Instruction)
用户在查看 AI 生成或修改的文件（包括 Word 文档 .docx/.doc、Excel 表格 .xlsx/.xls、Markdown 文档、程序代码、配置文件等）后，会随时在本地进行人工审阅、批注、文字修改或版式调整。

**在后续任何对话回合中对已有文件进行再次修改、升级或修复时，必须严格遵守以下原则：**

1. **先读后改（Read Before Write）**：
   * 严禁直接用缓存、旧脚本或通用模板盲目覆写已有文件。
   * 修改前必须先读取/解析目标文件的最新实际内容，识别用户在哪些段落、表格单元格或代码行中做出了人工修改。

2. **完整继承用户改动（Preserve All User Modifications）**：
   * 凡是用户手动调整过的内容（如修改的词句、增删的条款、调整的人员、自定义的格式等），必须作为最高优先级基准予以 **100% 完整保留与继承**。
   * 仅在用户明确要求的特定位置进行增量修正，严禁覆盖、回退或抹除用户的劳动成果。

3. **冲突提示与最小干预（Minimal Intervention & Safe Diffing）**：
   * 若修改要求与用户现有手动改动存在潜在逻辑冲突，应主动明确提示，不得擅自抹掉用户的手工内容。
